📘 What is the Technical Dossier?
The Technical Dossier is the full, standalone whitepaper page rendered on project.html?id=... when someone clicks your project. It acts as the official research thesis, software RFC, or technical report for this project.
It supports rich Markdown, tables, callout alerts (> [!NOTE], > [!TIP]), code blocks, diagrams, and media embeds.
